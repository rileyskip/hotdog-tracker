# DogTracker3000

Track how many hot dogs you eat. Sign in, log a count for any date, and keep a running total on this device.

Accounts and logs are stored in the browser with `localStorage`. Nothing is sent to a server.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What you can do

- Create an account or sign in
- Log 1–50 hot dogs for a date you choose
- See your all-time total, days logged, and latest entry
- Remove an entry
- Log out

## Scripts

- `npm run dev` — start the development server
- `npm run build` — build for production
- `npm run start` — serve the production build
- `npm run lint` — run the linter
